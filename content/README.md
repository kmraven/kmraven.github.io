# サイト内容の編集ガイド

手で編集するプロフィール・文章・画像は、この `content/` フォルダにまとめています。

| ファイル | 編集する内容 | 表示先 |
| --- | --- | --- |
| [profile.md](profile.md) | 現在の研究室の指定、写真、GitHub・X・LinkedIn・Google Scholar | ホーム・CV（写真はホームのみ） |
| [education.md](education.md) | researchmap以外で管理する公開用の学歴（普通部など） | CV |
| [history.md](history.md) | 各学歴・経歴の研究室名とURL | CVの該当する略歴。現在の研究室はホームにも表示 |
| [about/ja.md](about/ja.md) / [about/en.md](about/en.md) | 2〜4文程度の短い自己紹介 | 各言語のホームのプロフィール末尾 |
| [research/ja.md](research/ja.md) / [research/en.md](research/en.md) | 研究の問い・手法・意義、プロジェクトやデモの紹介 | 各言語のホームの研究紹介欄 |
| [career/ja.md](career/ja.md) / [career/en.md](career/en.md) | researchmap以外で管理する研究・実務経験 | CV |
| [misc/ja.md](misc/ja.md) / [misc/en.md](misc/en.md) | Misc.ページの本文・タイトルとApple MusicプロフィールのURL（`apple_music`） | 各言語のMisc. |
| `images/` | プロフィール写真、研究紹介の図 | 各Markdownから参照した場所 |

## メタデータの編集

各ファイルの先頭にある `---` と `---` の間が設定欄です。
空の `""` に文字やURLを記入します。引用符と行頭のスペースは残してください。

SNSなどのリンクも空欄なら非表示です。`profile.md` の説明文はサイトには掲載しません。
リンクはロゴやアイコンとして表示され、マウスやキーボードで選ぶとサービス名を確認できます。

写真を替えるときは `images/` に画像を置き、`photo` の相対パスを変更します。
表示用の画像はビルド時に自動で軽量化します。写真を非表示にするときは `photo` の行を削除します。

## 各時期の研究室の編集

`history.md` に、現在公開している学歴4件・経歴1件の入力欄を用意しています。
各項目の `lab.name.ja`、`lab.name.en`、`lab.url` に、その時期の研究室情報を記入します。
名前が空なら研究室の行を表示せず、URLだけ空なら名前のみを表示します。
名前が一方の言語にしかない場合は、その名称を両言語で使います。

ホームとCVの所属欄に表示する研究室は、`profile.md` の `current_lab` で選びます。
現在は `utokyo-2026` を指定しています。研究室名は `history.md` で一度だけ入力すれば反映されます。

略歴との対応には `category`（学歴・経歴）、`match.organization`（大学・機関名）、`match.start`（開始年月）を使います。
researchmapで並び順や終了年月が変わっても対応は保持されます。
大学・機関名や開始年月を変更した場合は、この設定も更新してください。
公開用データから消えた略歴の研究室情報は、ホームにも表示しません。

## 文章の編集

`about/` と `research/` には日英のMarkdownを用意しています。
先頭の `published: false` を `published: true` に変更し、下の本文を記入すると表示されます。
空の本文・HTMLコメントだけの本文・`published: false` の文章は表示されません。
日本語と英語は独立して管理するため、日本語だけ先に表示することもできます。

Markdownでは `[リンク名](https://example.org/)` のようにリンクを書けます。
研究紹介に図を入れる場合は `![図の説明](../images/figure.png)` のように参照します。

## researchmapとの役割分担

- 学歴・経歴・論文・発表・研究分野・大学や専攻などの所属：researchmapで更新し、JSONLから取り込みます。
- 研究室への補足、SNS、自己紹介、研究紹介、図や写真：このフォルダで編集します。
- `src/data/researchmap.public.json` は生成物です。直接編集しません。

researchmapの再取り込みでは、このフォルダを変更しません。
このフォルダはGitで管理します。`published: false` はサイト上の非表示設定なので、秘密のメモは置かないでください。

## 表示の確認

Node.js 24で `npm run dev` を実行し、表示されたlocalhostのURLを開きます。
開発サーバーの起動中は、保存した変更が自動で反映されます。
内容を確定する前に `npm run verify` で型・公開範囲・全ページのビルドを確認できます。
`main`にpushすると、検証・ビルドを通過した内容がGitHub Pagesに公開されます。

現在の研究室は生命知能システム研究室、修士課程はシステム生物学研究室（舟橋研究室）です。名称・URLは各研究室の公式サイトで確認しています。学部時代もシステム生物学研究室（舟橋研究室）であることをご本人に確認し、学部・修士の両方に記載しています。研究室への配属年月は学部の入学年月と同一とは限らないため、個別の所属期間は推定していません。将来のDC2期間の研究室は空欄です。

追加候補は、学士（理学）・修士（理学）の学位表記、期間・担当科目の分かるTA/RA経験、開催年と正式名称の分かるDeNAの開発コンペティション受賞です。学位はresearchmap側への登録を推奨します。短期インターンは役割と期間が確認できたものを選んで掲載すると、CVが読みやすくなります。

研究計画、投稿準備中・審査中の論文、申請中の助成は今回追加していません。LinkedInはログインが必要なため本文未確認です。原資料はこのリポジトリに複製していません。

現在の研究室の英名は、[公式英語ページ](https://www.ne.t.u-tokyo.ac.jp/index-e.html)の本文に合わせて `Bio-Intelligence Systems Lab` に研究室の通称を添え、`Bio-Intelligence Systems Lab (Takahashi–Shiramatsu Lab)` としています（2026年10月24日確認）。
